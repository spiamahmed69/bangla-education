# বাংলা এডুকেশন — অনলাইন কোর্স বিক্রির প্ল্যাটফর্ম

বাংলা-প্রথম কোর্স বিক্রির ফুল স্ট্যাক ওয়েবসাইট। React 19 + Vite + Tailwind v4, Firebase (Auth + Firestore), Vercel হোস্টিং।

CEO: **SP Siam Ahmed, Full Stack Web Developer**

## কী আছে

- হোমপেজ — হিরো, ক্যাটাগরি, কোর্স কার্ড, শিক্ষক, কেনার ধাপ (SP Patsala স্টাইলে: পিল ন্যাভবার, বড় হিরো, রঙিন ক্যাটাগরি টাইল, গাঢ় নেভি ফুটার)
- কোর্স তালিকা — সার্চ + ক্যাটাগরি ফিল্টার
- কোর্সের ভেতরের পেজ — ক্লাসের তালিকা (যেমন বাংলা কোর্সে: বহিপীর, অনুপ্রভা)
- ক্লাস পেজ — ইউটিউব ভিডিও এমবেড + প্রতিটি ক্লাসে নোটের PDF ডাউনলোড বাটন
- লগইন/রেজিস্টার — প্রথমে ইমেইলে যাচাই লিংক, তারপর পাসওয়ার্ড দিয়ে লগইন; এক অ্যাকাউন্টে সর্বোচ্চ ২টি ডিভাইস
- কেনার পেজ — লগইন ছাড়া কেনা যাবে না; বিকাশ/নগদ নম্বরে টাকা পাঠিয়ে ট্রানজাকশন আইডি বা শেষ ৩ সংখ্যা জমা
- আমার কোর্স — অ্যাডমিন অ্যাপ্রুভ করলেই ক্লাস খুলবে
- অ্যাডমিন প্যানেল — ড্যাশবোর্ড, পেমেন্ট অ্যাপ্রুভ/বাতিল, কোর্স CRUD, ক্লাস CRUD (ইউটিউব লিংক), PDF নোটের লিংক, ইউজার তালিকা (কোর্স/ডিভাইস), সেটিংস (বিকাশ/নগদ নম্বর)

## গুরুত্বপূর্ণ নিয়ম (কোডে এভাবেই বানানো)

- **না কিনলে ভিডিও লোড হয় না:** ক্লাস পেজে এনরোলমেন্ট অ্যাপ্রুভ না হলে YouTube iframe রেন্ডার হয় না, ভিডিওর লিংকও দেখানো হয় না। ভিডিও URL Firestore-এ আলাদা `lessonAccess` সাবকালেকশনে থাকে, `firestore.rules` শুধু এনরোল করা ইউজারকে পড়তে দেয়।
- **ভিডিও শুধু ইউটিউব লিংক**, নিজের সার্ভারে ভিডিও নেই। **PDF আপলোড নয়**, শুধু লিংক।
- **ImgBB চাবি কখনো রেপোতে/কোডে লিখবেন না।** ছবির জন্য ডিজাইন করা CSS কভার আর্ট ব্যবহার হয়; অ্যাডমিন চাইলে কোর্সে image URL (ImgBB লিংক) পেস্ট করতে পারে। ImgBB চাবি শুধু Vercel env-এ সার্ভার-সাইডে রাখার জন্য।
- **নমুনা কনটেন্ট:** সাইটের সব কোর্স/শিক্ষক নমুনা হিসেবে লেবেল দেওয়া। আসল কোর্স, শিক্ষক, ভিডিও ও PDF লিংক অ্যাডমিন প্যানেল থেকে বসাতে হবে।

## ডেমো মোড বনাম আসল Firebase

Firebase প্রজেক্ট এখনো বানানো হয়নি, তাই `VITE_FIREBASE_*` env var না থাকলে সাইট **ডেমো মোডে** চলে (localStorage-ভিত্তিক ডেমো Auth/অর্ডার) এবং সাইটের ওপরে “ডেমো মোড” ব্যানার দেখায়। ডেমো অ্যাডমিন: `admin@demo.local` / `admin123` — শুধু ডেমো দেখার জন্য, আসল Firebase-এ এই অ্যাকাউন্টের কোনো মানে নেই।

## আসল Firebase যুক্ত করা

1. Firebase Console-এ নতুন প্রজেক্ট বানান (Spark ফ্রি প্ল্যানই চলবে)।
2. Authentication → Sign-in method → **Email/Password** চালু করুন।
3. Firestore Database বানান (asia-southeast1), তারপর `firestore.rules` ফাইলের নিয়মগুলো Firebase Console-এর Rules-এ বসিয়ে Publish করুন।
4. Project settings → Your apps → Web app থেকে কনফিগ নিয়ে Vercel-এর Environment Variables-এ বসান: `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_STORAGE_BUCKET`, `VITE_FIREBASE_MESSAGING_SENDER_ID`, `VITE_FIREBASE_APP_ID`। তারপর Vercel-এ Redeploy করুন।
5. প্রথম অ্যাডমিন: সাইটে রেজিস্টার করুন, তারপর Firebase Console → Firestore → `users/{uid}` ডকুমেন্টে `role` ফিল্ড `admin` করে দিন।
